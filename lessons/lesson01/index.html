    運動学から動力学へ

    教科書 p.105
    動力学とは
    物体に作用する「力」と、その力によって生じる「運動状態の変化」との関係を明らかにする力学を動力学（dynamics）という。
    教科書 第6章 冒頭（p.105）より

    第6章では、物体を質点とみなせる場合、つまり物体全体が同じように動く並進運動を扱います。回転を伴う運動は第7章で扱います。

    基礎力学Ⅰの復習：等加速度運動

    加速度 a が一定のとき、速度 v、変位 s、時間 t の間には次の関係がありました（初速度 v0、初期変位 s0）。

    v = at + v0(5.15)
    s = 12at2 + v0t + s0(5.16)
    v2 − v02 = 2as　（s0 = 0 のとき）(5.17)

    運動学は物体がどのように動くかを記述します。動力学では、その加速度 a がどのような力によって生じるかを考えます。今回の例題では、運動方程式で a を求め、式(5.17)で速度や距離と結びつける、という使い方を何度もします。

    第一法則 ― 慣性の法則

    教科書 p.105
    第一法則
    あらゆる物体は、外部から力を受けない限り、静止、あるいは等速直線運動を続ける

    外力を受けない限り、物体が持っている速度は（速度 0 も含めて）そのまま保たれ、物体自身が速度を変えることはありません。物体の持つこの性質を慣性（inertia）といい、第一法則を慣性の法則ともいいます。

    床をすべらせた物体がやがて止まるのは、「力を受けないと止まる」からではありません。床から摩擦力という外力を受けているからです。下の図で摩擦を小さくしていくと、この違いが確かめられます。

    実験　摩擦の大きさと物体の運動動摩擦係数 μ を変えて「押し出す」
    経過時間 0.00 s
    速さ 3.00 m/s
    移動距離 0.00 m

    初めの速さは 3.00 m/s。摩擦力による加速度は −μg です（g = 9.80 m/s²）。μ = 0 にすると速さは変わらず、物体は等速直線運動を続けます。

    摩擦のない水平な氷の上に、物体が静止している。外から力を加えなければどうなるか。

    静止したままです。第一法則の「静止、あるいは等速直線運動を続ける」の静止の場合にあたります。速度 0 も「保たれる速度」の一つです。

    電車が急に動き出すと、車内の人は後ろへよろけます。人の体は慣性によってそれまでの状態（静止）を続けようとするからです。加速している電車の中から見た運動の扱い方は、次回（§6.2 慣性力）で学びます。

    第二法則 ― 運動の法則と運動方程式

    教科書 p.105〜106
    第二法則
    物体に外部から力が作用するときに生じる加速度は、力の大きさに比例し、その方向、向きは力の方向、向きと同じである

    外力の大きさを F、加速度の大きさを a とすると、この法則は次式で表されます。

    F = ma(6.1)

    比例定数 m は、同じ力を加えたときの動きにくさ、すなわち物体の慣性の度合いを表す量で、質量（mass）といいます。単位は kg です。式(6.1)を運動方程式（equation of motion）と呼びます。

    • F は、物体に働く力をすべて合わせた力（合力）です。
    • F = 0 なら a = 0 で、速度は変わりません。つまり第二法則は第一法則を含んでいると解釈できます。
    実験　力・質量・加速度なめらかな水平面。F と m を変えて「走らせる」
    加速度 a = F/m
    10 m 進むまでの時間

    右のグラフの直線の傾きは 1/m です。質量が大きいほど傾きが小さく、同じ力でも加速しにくくなります。灰色の四角は 0.5 秒ごとの位置です。

    力の単位と重さ

    1 N（ニュートン）は、質量 1 kg の物体に 1 m/s² の加速度を生じさせる力です。

    1 N = 1 kg·m/s²

    地球上の物体には重力が働きます。重力による加速度（重力加速度）を g とすると、質量 m の物体に働く重力の大きさ、すなわち重さは W = mg です。この授業では教科書に合わせて g = 9.80 m/s² を使います。

    質量 m重さ W = mg
    意味物体の慣性の度合い物体に働く重力の大きさ
    単位kgN
    場所による違い変わらないg が変われば変わる
    例10.0 kg10.0 × 9.80 = 98.0 N
    質量 2.0 kg の物体に 6.0 N の力（合力）が働く。加速度はいくらか。同じ力を質量 4.0 kg の物体に加えるとどうなるか。

    a = F/m = 6.0/2.0 = 3.0 m/s²。質量が 2 倍の 4.0 kg では a = 6.0/4.0 = 1.5 m/s² と半分になります。加速度は力に比例し、質量に反比例します。

    第三法則 ― 作用・反作用の法則

    教科書 p.106
    第三法則
    すべての力の作用に対し、つねにそれと大きさの等しい逆向きの作用（反作用）が生じる。すなわち、任意の物体間の相互に働く力の大きさはつねに等しく逆向きに作用する

    磁石が砂鉄を引きつけるとき、砂鉄だけが一方的に引かれているように見えますが、砂鉄も同じ大きさの力で磁石を引いています。力は単独では存在できず、必ず対（pair）になって現れます。

    • 作用と反作用は、互いに相手の物体に働く（働く物体が異なる）
    • 大きさが等しく、向きが逆

    よく混同されるのがつり合いです。つり合いは一つの物体に働く複数の力の関係、作用・反作用は二つの物体の間で及ぼし合う力の関係です。下の図で確かめましょう。

    図解　机の上に静止している本ボタンで力の組を切り替え

    本と机は、見やすさのために少し離して描いています（実際には接しています）。同じ作用線上の力は、重ならないよう左右に少しずらしています。

    馬が荷車を引く力と、荷車が馬を引く力は大きさが等しく逆向き。それなのに荷車が動き出せるのはなぜか。

    2つの力は別々の物体（荷車と馬）に働くので、打ち消し合いません。荷車が動くかどうかは荷車に働く力だけで決まります。荷車に働く水平方向の力は、馬が荷車を引く力と地面からの摩擦力です。前者が後者より大きければ、荷車は前向きに加速します。

    自由体線図と運動方程式の作り方

    教科書 p.106〜107

    運動方程式は、次の手順で作ると間違いにくくなります（教科書 p.106〜107「運動方程式(6.1)の作り方」）。

    1. ① 初めに、どの部分の運動について考えるかを明確にする。そのためには自由体線図を描くとよい。
    2. ② その部分の質量を m とする。
    3. ③ その部分に作用する力をもれなく挙げて、その合力を F とする。
    4. ④ その部分の加速度を a とする（F および a の符号は、変位が増加する向きを正とする）。
    5. ⑤ 上記①〜④を確かめてから運動方程式 F = ma に代入する。

    自由体線図は、注目する物体をまわりから切り離し、その物体が受ける力だけを描いた図です。描く力は、離れていても働く重力と、その物体に接しているもの（ひも・床・手など）から受ける力です。その物体が相手に及ぼす力は描きません。

    例題6.1 ― 物体を鉛直に引き上げる

    教科書 p.106〜107
    教科書 例題6.1質量 m = 60 kg の物体を鉛直上方へ h = 5 m 移動させたとき、v = 2 m/s の速度を得るために必要な力 F1 を求めよ。

    物体は静止の状態から動き出し（v0 = 0）、力 F1 は一定とします。前節の手順どおり、上向き（変位が増加する向き）を正とします。

    1. 物体に働く力は、引き上げる力 F1（上向き）と重力 mg（下向き）。合力は F = F1 − mg。運動方程式は
      F1 − mg = ma(a)
    2. 等加速度運動の関係 v² − v0² = 2as（式5.17）で、v0 = 0、s = h とおくと
      a = v22h = 222 × 5 = 0.400 m/s2
    3. 式(a)より
      F1 = m(g + a) = 60 × (9.80 + 0.400) = 612 N

    物体の重さは mg = 588 N です。引き上げる力はそれより ma = 24 N だけ大きく、この差が物体を加速させています。

    計算器　引き上げる力の内訳数値を変えて F1 の変化を見る
    加速度 a = v²/2h
    重さ mg
    引き上げる力 F1
    同じ物体を、一定の速さで引き上げ続けるときの力 F1 はいくらか。

    速さが一定なら a = 0 なので、式(a)から F1 = mg = 60 × 9.80 = 588 N。上に動いていても、加速していなければ力は重さと等しくなります。上の計算器で v = 0 にすると同じ結果になります。

    例題6.2 ― 急ブレーキのタイヤ跡から速度を求める

    教科書 p.107〜108
    教科書 例題6.2急ブレーキをかけて自動車が止まった。タイヤの跡が鮮明に残っていることから、ブレーキをかけた後タイヤは回転していないと判断できる。路面に残された直線状のタイヤ跡を測定したところ、その距離 s は 50 m で、路面状態からタイヤと路面の摩擦係数 μ は 0.7 であった。この自動車のブレーキをかける前の速度 v0 [km/h] は、どれほどか。

    進行方向を正とします。自動車に働く力は、重力 mg、路面からの抗力 R、摩擦力 f です。上下方向には加速しないので R = mg、したがって摩擦力の大きさは μR = μmg です。

    1. 空気抵抗を無視すれば、水平方向の外力は摩擦力 f = −μmg のみ（負号は、変位の増加する向きに対して摩擦力が逆向きであることを表す）。運動方程式は
      −μmg = ma　より　a = −μg
    2. 式(5.17) v² − v0² = 2as で、止まったとき v = 0 とおくと −v0² = −2μgs、すなわち
      v0 = √2μgs = √2 × 0.7 × 9.80 × 50 = 26.2 m/s = 94.3 km/h

    m/s から km/h へは 3.6 倍します（1 m/s = 3600 m/h = 3.6 km/h）。答えに質量 m が含まれないことにも注目してください。摩擦力も「動きにくさ（慣性）」も m に比例するので、重い車でも軽い車でも同じ結果になります。

    実験　タイヤ跡の長さと速度μ と s を変えて「ブレーキ」
    加速度 a = −μg
    ブレーキ前の速度 v0

    右は、ブレーキ中の自動車を一つの物体とみなした自由体線図です（mg と R は同じ作用線上にありますが、左右にずらして描いています）。アニメーションは実際の時間の 1/4 に縮めています。

    同じ路面で、タイヤ跡が 4 倍の長さだったら、ブレーキ前の速度は何倍か。

    v0 = √(2μgs) は s の平方根に比例するので、√4 = 2 倍です。逆にいえば、速度が 2 倍になると止まるまでの距離は 4 倍になります。

    例題6.3 ― 定滑車につるした2個のおもり

    教科書 p.108〜109
    教科書 例題6.3定滑車にひもをかけ、その両端に2個のおもりをつり下げた装置がある。m1 > m2 とし、定滑車とひもの質量を無視できるものとするとき、おもりの加速度 a とひもに作用する張力 T を求めよ。

    ひもは伸びないので、2つのおもりの加速度の大きさは等しく a です。滑車とひもの質量を無視でき、滑車の軸の摩擦もないものとすると、ひもの張力はどこでも同じ T になります。おもりごとに自由体線図を描き、それぞれ変位が増加する向きを正にとります。

    注目する物体正の向き運動方程式
    おもり1（m1）下向きm1g − T = m1a　(a)
    おもり2（m2）上向きT − m2g = m2a　(b)

    (a)と(b)を辺ごとに加えると T が消えて (m1 − m2)g = (m1 + m2)a。これを(a)に戻すと T も求まります。

    a = m1 − m2m1 + m2g(c)
    T = 2m1m2m1 + m2g(d)
    実験　おもりの質量と加速度・張力質量を変えて「放す」

    自由体線図の矢印の長さは力の大きさに比例させています（2つの図で同じ縮尺）。

    加速度 a（おもり1が下がる向き）
    張力 T
    m2g ／ m1g

    式(c)(d)で、(1) m1 = m2 のとき、(2) m2 を 0 に近づけたとき、それぞれどうなるか。結果は物理的に妥当か。

    (1) a = 0、T = m1g。両側の重さが等しく、つり合った状態です。
    (2) a → g、T → 0。反対側に何もつるさなければ、おもり1は自由落下し、ひもは張りません。
    どちらも予想どおりの結果なので、式(c)(d)が正しいことの確かめになります（第12節）。

    例題6.4 ― 釘にかけて滑り落ちるひも

    教科書 p.109〜110発展
    教科書 例題6.4長さ l [m]、質量 m [kg] のひも AB を水平な釘にかけて滑り落とす。一方のひもの長さが s [m] となったとき、他方の任意の点 C における張力 T を求めよ。ここで、ひもと釘の間の摩擦は無視できるものとする。

    ひもの単位長さ当たりの質量を ρ とすると m = ρl です。「どの部分の運動を考えるか」を2回選び直すのがこの例題の要点です。

    1. ひも全体に注目します。ひもに沿って、長い側（B 側）が下がる向きを正とします。長い側の重さ ρ(l − s)g は正の向き、短い側の重さ ρsg は負の向きに働くので
      ρ(l − s)g − ρsg = ρla　より　a = l − 2slg
      l > 2s なので a は正です。ひもの内部で及ぼし合う張力は、作用・反作用として打ち消し合うので、この式には現れません。
    2. 次に、CB 部分（長さ x、質量 ρx）だけに注目します。この部分には下向きに重さ ρxg、上向きに点 C の張力 T が働き、加速度は下向きに a なので
      ρxg − T = ρxa
    3. a を代入し、mg = ρlg を使うと
      T = ρx(g − a) = 2ρsxlg = 2mgsl2x
    図解　ひもの各点の張力s/l と点 C の位置を変える
    加速度 a/g = 1 − 2s/l
    点 C の張力 T/mg
    釘の位置の張力 /mg

    グラフの横軸は、ひもに沿って端 A から測った長さです。張力は両端で 0、釘の位置で最大になります。短い側でも同じように考えると（上向きに加速する長さ y の部分：T − ρyg = ρya）、釘の位置の張力が長い側から求めた値と一致することが確かめられます。

    例題1.1 ― 糸で連結した2物体

    §6.1 に準拠した独自例題
    例題1.1なめらかな水平面上で、質量 m1 の物体1と質量 m2 の物体2が、伸びない軽い糸で結ばれている。物体1を水平右向きの力 F で引いたとき、2物体の加速度 a と糸の張力 T を求めよ。

    右向きを正とし、物体ごとに水平方向の運動方程式を立てます（上下方向は重力と抗力がつり合い、加速しません）。

    注目する物体水平方向に受ける力運動方程式
    物体1F（右向き）、T（左向き）F − T = m1a
    物体2T（右向き）T = m2a
    a = Fm1 + m2,　T = m2m1 + m2F

    2物体をまとめて一つの物体とみなすと、糸の張力は内部で及ぼし合う力なので現れず、F = (m1 + m2)a から直ちに a が求まります。例題6.4 でひも全体に注目したのと同じ考え方です。

    まとめと次回

    • 第一法則（慣性の法則）：外部から力を受けない限り、物体は静止、あるいは等速直線運動を続ける。
    • 第二法則（運動の法則）：F = ma（式6.1、運動方程式）。F は合力、m は慣性の度合いを表す質量。
    • 第三法則（作用・反作用の法則）：2物体の間で及ぼし合う力は、大きさが等しく逆向き。働く物体が異なるので、つり合いとは別物。
    • 運動方程式の作り方：注目する部分を決めて自由体線図を描く → 質量・力（もれなく）・加速度を決める（変位が増加する向きを正）→ F = ma に代入。
    • 加速度が求まれば、式(5.15)〜(5.17)で速度・距離・時間と結びつけられる。
    • 答えは、単位・特別な場合・符号・大きさで確かめる。
