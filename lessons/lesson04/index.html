    積分で慣性モーメントを求め、剛体の並進と回転を同時に扱う ― 教科書 第7章 §7.2.2〜§7.3（p.129〜137）と章末演習の複合形状の考え方

    この回の目標

    • 物体を微小要素に分けて積分し、基本形状（棒・長方形板・円板・円柱・球）の慣性モーメントを求められる（例題7.2〜7.6）
    • 表7.1 の慣性モーメントと回転半径を使える
    • 複合形状（中空円板・穴あき円板）の慣性モーメントを、足し引きと平行軸の定理で求められる
    • 剛体の平面運動を、ΣF = ma（式7.13）と ΣT = IGα（式7.14）の連立で解ける（例題7.8〜7.10）
    • 滑らずに転がる条件 a = Rα を使える

    進め方：各節を「読む → 図を動かす → 考えてみようで確かめる」の順に進めてください。節の見出しにある 音声解説 で、その節の解説を聞くこともできます。教科書（p.128〜137）を手元に置いて、見比べながら学習してください。第3回の「与えられた値として使う」から一歩進み、この回では積分で値を導きます。

    本時の目標と進め方

    教科書 §7.2.2〜§7.3　p.128〜137

    第3回では、慣性モーメントの定義と、平行軸の定理・直交軸の定理を学びました。表7.1 の値は「与えられた値」として使うだけでした。この回では、その値を積分で導き、さらに剛体が並進しながら回る運動（平面運動）を扱います。まず、第3回の内容を 3 行で確かめます。

    第3回の復習（3 行）
    1. 慣性モーメントの定義（式7.6）：I = ∫r²dm　（r は軸から要素までの距離、dm は要素の質量）
    2. 平行軸の定理：I = IG + md²　（重心 G を通る軸に平行で距離 d だけ離れた軸のまわりの I）
    3. 直交軸の定理（板だけ）：Iz = Ix + Iy　（z 軸は板に垂直、x・y 軸は板の面内で直交する軸）
    記号に注意　トルクは第3回と同じ T です（教科書の本文には合成モーメント M という書き方も出てきますが、同じものです）。例題7.2 の a は断面積、§7.3 の a は加速度で、別の量です。例題7.8 の R は球の半径で、第1・2回の抗力 R とは別です。

    細い棒の慣性モーメント ― 例題7.2

    教科書 例題7.2　図7.5　p.129〜130

    長さ l、質量 m、断面積 a の一様な細い棒の、重心 G を通り棒に直角な軸に関する慣性モーメント IG を求めます。密度を ρ とすると、G から距離 r にある長さ dr の微小要素の質量は次のとおりです。

    dm = ρa dr　（ρ は密度、a は断面積。加速度ではありません）

    棒全体の質量は m = ρal です。式(7.6)に代入して、r を −l/2 から l/2 まで積分します。

    IG = ∫−l/2l/2 ρa r2dr = 2ρa∫0l/2 r2dr = 2ρa·13l38 = ρal·l212 = ml212(a)

    端 A を通る軸は、平行軸の定理（第3回）で G の軸から l/2 だけ離れています。回転半径は k = √(I/m) です。

    IA = IG + m(l2)2 = ml212 + ml24 = ml23(b)
    kG = l2√3(c)　　kA = l√3(d)

    下の図は、積分の中身を目で見るためのものです。棒を G のまわりに N 個の等しい要素に分け、各要素の質量 m/N に、要素の中心までの距離 ri の 2 乗を掛けて足します。N を増やすと、足し合わせた値は積分の値 ml²/12 に近づきます。

    実験　棒を G のまわりの要素に分けて Σ (m/N)ri² を計算する要素数 N を 1 → 50 に増やす
    Σ (m/N)ri²
    積分の値 IG = ml²/12
    差（Σ の方が小さい分）
    IA = IG + m(l/2)²
    回転半径 kG = l/(2√3)
    回転半径 kA = l/√3

    上の図は、棒の長さを画面上の 540 px に合わせて描いています（l を変えても棒は同じ長さに見えます）。下の棒グラフの高さは ri² に比例し、最大の高さ（r = ±l/2）は 120 px です。質量 m/N は全要素で同じなので、高さの合計が Σ の大小を表します。曲線は r² で、積分は −l/2〜l/2 の曲線の下の面積に m/l を掛けたものです。右のグラフは N を 1 から 50 まで変えたときの Σ の値で、破線が ml²/12 です。N = 1 では要素の中心が G にあるので r = 0 となり、Σ = 0 です。Σ = (ml²/12)(1 − 1/N²) で、N を大きくするほど ml²/12 に近づきます。

    m = 1.0 kg、l = 1.0 m の棒で N = 4 のとき、Σ はいくらか。また l を 2 倍にすると IG は何倍になるか。

    要素の中心は G から ±0.125 m、±0.375 m、各要素の質量は 0.25 kg。Σ = 0.25 × (2 × 0.125² + 2 × 0.375²) = 0.25 × 0.3125 = 0.0781 kg·m²。式 (ml²/12)(1 − 1/N²) = 0.0833 × (15/16) でも同じです。真の値 0.0833 kg·m² より 6％ ほど小さい値です。IG = ml²/12 は l の 2 乗に比例するので、l を 2 倍にすると 4 倍（0.333 kg·m²）になります。上の図で l = 2.0 m にして確かめられます。

    長方形板の慣性モーメント ― 例題7.3

    教科書 例題7.3　図7.6　p.130〜131

    幅 b、高さ h、厚さ t、質量 m の一様な長方形板について、板の中心 O を通る x 軸、y 軸、z 軸（板に垂直）のまわりの慣性モーメントを求めます。x 軸に平行な、幅 b・厚さ dy の帯状の微小要素（x 軸からの距離 y）を考えると、その質量は次のとおりです。

    dm = ρtb dy

    帯の中のどの点も x 軸から同じ距離 y にあるので、帯全体の慣性モーメントは y²dm です。y を −h/2 から h/2 まで積分します。

    Ix = ∫−h/2h/2 ρtb y2dy = 2ρtb∫0h/2 y2dy = mh212(a)

    同様に、y 軸に平行な帯で積分すると Iy = mb²/12 …(b)。板に垂直な z 軸は、直交軸の定理（第3回）により次のとおりです。

    Iz = Ix + Iy = mh212 + mb212 = mh2 + b212(c)

    回転半径は kx = h/(2√3) …(d)、ky = b/(2√3) …(e)、kz = √(h² + b²)/(2√3) …(f) です。第3回で与えた「b = 0.60 m、h = 0.40 m の板」を、今回は積分で導きます。

    実験　帯状の微小要素と dIx = y²dm帯の位置 y と板の寸法を変える
    帯 1 本の質量 dm = m·(h/40)/h
    帯 1 本の dIx = y²dm
    Ix = mh²/12
    Iy = mb²/12
    Iz = Ix + Iy
    回転半径 kx、ky、kz

    質量は m = 1.0 kg で固定です。左の図は 1 m あたり 230 px の縮尺で、板を 40 本の帯に分けています（帯の厚さ dy = h/40）。青の濃さは y² に比例し、強調した帯がスライダーで選んだ位置です。右のグラフは、帯の位置 y と、単位厚さあたりの慣性モーメント dIx/dy = m y²/h［kg·m］の関係で、曲線の下の面積が Ix です。縦軸・横軸の範囲は固定なので、h を小さくすると面積が小さくなる様子がそのまま見えます。b を変えても、Ix（面積）は変わりません。

    b = 0.30 m、h = 0.90 m、m = 1.0 kg の細長い板で、Ix、Iy、Iz を求めよ。どちらの軸のまわりが回しやすいか。

    Ix = mh²/12 = 0.81/12 = 0.0675 kg·m²、Iy = mb²/12 = 0.09/12 = 0.00750 kg·m²、Iz = 0.0675 + 0.00750 = 0.0750 kg·m²。I が小さい軸ほど同じトルクで速く回ります。細長い板では、長い辺（高さ h）に平行な y 軸のまわりが回しやすく、Iy は Ix の 1/9 です。

    円板の慣性モーメント ― 例題7.4

    教科書 例題7.4　図7.7　p.131〜132

    半径 R、厚さ t、質量 m の円板について、中心 O を通る z 軸（板に垂直）のまわりの慣性モーメントを求めます。中心から距離 r、幅 dr の円環状の微小要素を考えると、その体積は（周の長さ 2πr）×（幅 dr）×（厚さ t）なので、質量は次のとおりです。

    dm = 2πρt r dr

    円環のどの点も軸から r だけ離れているので、円環の慣性モーメントは r²dm です。r を 0 から R まで積分します。

    Iz = ∫0R r2(2πρt r dr) = 2πρt∫0R r3dr = πρtR42 = mR22(a)

    最後の変形は、円板の質量 m = ρπR²t を使っています。x 軸と y 軸（板の直径）のまわりの慣性モーメントは対称性から等しいので、直交軸の定理 Iz = Ix + Iy により次のとおりです。

    Ix = Iy = Iz2 = mR24(b)

    回転半径は kx = ky = R/2 …(c)、kz = R/√2 …(d) です。下の図では、円板を同じ幅 R/N の N 個の円環に分け、各円環の質量 dmi に ri²（ri は円環の中心半径）を掛けて足します。円環の幅は dr = R/N、質量は dm = 2πρt r dr です。

    実験　円板を円環状の要素に分けて Σ dmiri² を計算する要素数 N を 1 → 30 に増やす
    Σ dmiri²
    積分の値 Iz = mR²/2
    差（Σ の方が小さい分）
    直径のまわり Ix = Iy = Iz/2
    回転半径 kx = R/2
    回転半径 kz = R/√2

    左の図の O は中心で、z 軸は紙面に垂直です。円板は、R を変えても画面上で同じ大きさ（半径 140 px）に描いています。円環の濃さは dmiri²（∝ ri³）に比例し、外側の円環ほど濃く、dmi = 2m ri(R/N)/R² です。右のグラフは、横軸が r、縦軸が単位幅あたりの慣性モーメント dI/dr = 2m r³/R²［kg·m］で、棒の幅は R/N、棒の面積の合計が Σ、曲線の下の面積が積分の値 mR²/2 です（縦軸の目盛りは m、R に合わせて変わります）。Σ = (mR²/2)(1 − 1/(2N²)) で、N = 1 では mR²/4（積分の値の半分）、N を大きくすると mR²/2 に近づきます。

    m = 1.0 kg、R = 0.30 m の円板で N = 2 のとき、Σ はいくらか。

    円環の幅は 0.15 m、中心半径は r1 = 0.075 m、r2 = 0.225 m。質量は dmi = 2m ri(R/N)/R² より dm1 = 0.25 kg、dm2 = 0.75 kg（合計 1.0 kg）。Σ = 0.25 × 0.075² + 0.75 × 0.225² = 0.00141 + 0.0380 = 0.0394 kg·m²。積分の値 0.0450 kg·m² の 87.5％ で、式 (mR²/2)(1 − 1/8) とも一致します。

    円柱の慣性モーメント ― 例題7.5

    教科書 例題7.5　図7.8・7.9　表7.1　p.128〜129、132〜133

    半径 R、高さ h、質量 m の円柱について、底面の中心 O を通る直径の方向の y 軸と、中心軸（z 軸）のまわりの慣性モーメントを求めます。図7.9 のように、底面から高さ z にある厚さ dz の円板状の微小要素をとります。この円板の y 軸（直径）のまわりの慣性モーメントは、例題7.4 の式(b)（円板の直径軸 mR²/4）と平行軸の定理（y 軸は円板の直径軸から z だけ離れている）から次のとおりです。ここで円板の質量は ρπR²dz です。

    dIy = ρπR2dz·R24 + ρπR2dz·z2(a)

    これを z = 0 から h まで積分し、m = ρπR²h を使います。

    Iy = ρπR4h4 + ρπR2h33 = m(R24 + h23)(c)

    重心 G は底面から h/2 の高さにあります。y 軸に平行で G を通る軸のまわりは、平行軸の定理 Iy = IG + m(h/2)² より次のとおりです。

    IG = m(R24 + h212)(d)

    中心軸（z 軸）のまわりでは、円板状要素の dIz = ρπR²dz·R²/2 …(e) を積分して Iz = mR²/2 となり、円板と同じ結果です。

    軸の呼び方　底面の直径の軸を、例題7.5 は「y 軸」、表7.1 は「y′ 軸」と呼びます。例題7.5 の y 軸 ＝ 表7.1 の y′ 軸（Iy = Iy′ = m(3R² + 4h²)/12）です。表7.1 の Ix = Iy = m(3R² + h²)/12 は、重心 G を通る直径の軸で、上の IG と同じ値です。軸を示さずに「円柱の慣性モーメント」とは言えません。
    実験　円柱の高さ h を変えて IG、Iy、Iz を比べる要素の高さ z と寸法を変える
    IG（現在の h は点）mR²/4（円板の直径軸）mh²/12（細い棒）Iz = mR²/2
    重心を通る直径軸 IG = m(R²/4 + h²/12)
    底面の直径（y 軸＝y′ 軸）Iy = m(R²/4 + h²/3)
    中心軸 Iz = mR²/2
    極限 h → 0：mR²/4（例題7.4 の式(b)）
    極限（細い棒）：mh²/12（例題7.2）
    高さ z、厚さ dz = h/50 の円板の dIy

    左の図は、h と 2R の大きい方が 230 px になるように縮尺を自動で変えています（縮尺は図の左下に表示）。青い円板が高さ z の微小要素で、厚さ dz は見やすいように h/50 の 5 px 以上に描いています。破線は G を通り y 軸に平行な軸です。右のグラフは、現在の m、R のもとで h を 0〜1 m に変えたときの IG です。h が小さいと mR²/4 に、h が大きい（R が h に比べて小さい）と mh²/12 に近づきます。

    R = 0.10 m の円柱で、重心を通る直径軸の IG が中心軸の Iz と等しくなる高さ h は何 m か。

    IG = Iz より R²/4 + h²/12 = R²/2。整理すると h²/12 = R²/4、h² = 3R²、h = √3R = 0.173 m。このとき両方とも mR²/2 = 0.00500 kg·m²（m = 1.0 kg）です。h がこれより小さい（平たい）円柱では IG < Iz（中心軸のまわりが回しにくい）、大きい（細長い）円柱では IG > Iz です。図のスライダーは 0.01 m 刻みなので、h = 0.17 m や 0.18 m で IG が Iz に近いことを確かめられます。

    球の慣性モーメント

    教科書 §7.2.2　例題7.6　図7.10　p.133〜134
    例題7.6（球）半径 R、質量 m の球の重心軸（z 軸）に関する慣性モーメント Iz を求めよ。

    球を、z 軸に垂直な円板状微小要素（厚さ dz の薄い円板）に分けます。球の中心 O から高さ z にある円板の半径を r とすると、円板は球の表面にふれているので、

    r2 = R2 − z2

    です。円板の質量は ρπr²dz（ρ は密度 [kg/m³]、πr²dz は円板の体積）。この円板の z 軸に関する慣性モーメントは、例題7.4 の式(a)（円板の Iz = mR²/2。第 4 節で導いた結果）を円板の質量と半径 r で使って、

    dIz = ρπr2dz · r22 = ρπ2(R2 − z2)2dz(a)

    球全体では、z を −R から R まで積分します。

    Iz = ρπ2∫−RR(R4 − 2R2z2 + z4)dz = 8ρπR515(b)

    球の質量は m = 4ρπR³/3 なので、ρπ = 3m/(4R³) を (b) に入れると、

    Iz = m · 2R25(c)

    となります。表7.1 の球の値（Ix = Iy = Iz = 2mR²/5）と一致します。球はどの向きの重心軸でも同じ形なので、3 つの軸で値が等しくなります。

    実験　円板の位置 z を動かすz を −R → R。円板の半径と dIz の変わり方

    円板 1 枚あたりの dIz/dz と z の関係

    円板の半径 r
    dIz/dz
    球全体 Iz = 2mR²/5
    円板 400 枚の和（数値）

    同じ m、R の物体どうしの比べ（中心軸のまわり）

    左の図は R をいつも同じ大きさに描き、円板の厚さ dz は見やすいよう実際より厚くしています。右のグラフは円板 1 枚あたりの dIz/dz = (3m/8R³)(R² − z²)² を表し（縦軸の最大は z = 0 の値 3mR/8）、曲線の下の面積が Iz です。赤道面（z = 0）の円板が最も大きく効き、両極（z = ±R）では半径が 0 になって効きません。下の棒グラフの長さは 1 mR² を 300 px にしています。

    質量が軸から遠いほど大きい　同じ質量・同じ半径でも、球は 0.4mR²、円板や円柱（中心軸）は 0.5mR²、円環は 1.0mR² です。質量が軸の近くに集まっている球ほど I は小さくなります。
    質量 m = 3.0 kg、半径 R = 0.20 m の球の、重心軸のまわりの I はいくらか。

    I = 2mR²/5 = 2 × 3.0 × 0.20²/5 = 0.0480 kg·m²。図の m と R のスライダーを合わせると、読み取り欄の Iz がこの値になります。

    教科書 §7.2.2　表7.1　p.128〜129

    複合形状の慣性モーメント

    教科書 第7章 演習問題【2】【3】【4】（p.138）の考え方応用

    穴のあいた円板や、太さの違う部分をもつ棒のように、いくつかの単純な形が組み合わさった物体を複合形状と呼びます。慣性モーメントは I = ∫r²dm なので、物体を部分に分けて、同じ軸に関する値を足し合わせることができます。穴の部分は、穴の無い円板から引くと考えます。

    複合形状の求め方
    ① 物体を、表7.1 で値がわかる形（円板・円柱・棒など）の足し引きに分ける。
    ② 質量は体積の比（厚さが一様な板なら面積の比）で分ける。
    ③ 同じ軸に関する値どうしを足し引きする。部品の重心が軸から d 離れているときは、平行軸の定理 I = IG + md² で軸を移してから足す。
    実験　足し引きで求める中空円板と、穴あき円板（穴の数・大きさ・位置を選ぶ）

    ① 中空円板の式を導く

    厚さと密度が一様なので、質量は面積に比例します。外半径 R2・内半径 R1 の中空円板の質量を m とすると、穴の無い円板（半径 R2）の質量 M2 と、穴の部分（半径 R1 の円板）の質量 M1 は、

    M2 = mR22R22 − R12、　M1 = mR12R22 − R12

    です（M2 − M1 = m）。どちらも中心を通り円板に垂直な軸（z 軸）に関して、円板の式 Iz = MR²/2（例題7.4）が使えるので、

    Iz = M2R22 − M1R122 = m(R24 − R14)2(R22 − R12) = m(R12 + R22)2

    R1 → 0 なら mR2²/2（穴の無い円板）、R1 → R2 なら mR2²（円環、表7.1）に近づきます。

    ② 穴あき円板の式を導く

    穴を開ける前の円板（半径 R、質量 M）の Iz = MR²/2 から、穴の部分の I を引きます。半径 rh の穴 1 個の部分の質量は面積比で mh = M(rh/R)² です。穴の中心は円板の中心 O から d 離れているので、O を通る z 軸に関する穴 1 個の部分の I は、穴の中心を通る軸の値 mhrh²/2 に、平行軸の定理の mhd² を足したものです。

    Iz = MR22 − n[mhrh22 + mhd2]
    ① で R2 = 0.20 m、m = 1.0 kg のまま、内半径を R1 = 0.15 m にすると Iz はいくらか。② で穴を n = 2 個にすると I と質量は。

    ①：Iz = m(R1² + R2²)/2 = 1.0 × (0.15² + 0.20²)/2 = 0.0313 kg·m²（R1 = 0.10 m の 0.0250 より大きい。穴が小さくなり円環に近づくため）。
    ②：n = 2 のとき I = 0.0800 − 2 × (0.000128 + 0.002304) = 0.0751 kg·m²、質量 = 4.0 − 2 × 0.160 = 3.68 kg。

    剛体の平面運動

    教科書 §7.3　式(7.13)(7.14)　p.134〜135

    剛体が、重心を含む平面内でいくつかの力を受けると、その平面内で並進運動（向きを変えずに位置が動く運動）と回転運動を同時にします。教科書は、外力の合力 F が重心に作用する並進運動と、合成モーメントによる重心軸まわりの回転運動を重ね合わせたものが剛体の平面運動だと説明しています。この二つに運動方程式を立てます。

    剛体の平面運動の運動方程式
    外力の合力を ΣF、質量を m、重心の加速度を a、重心軸（平面に垂直）に関する慣性モーメントを IG、外力による合成モーメント（トルク）を ΣT、角加速度を α とすると、
    ΣF = ma(7.13)
    ΣT = IGα(7.14)
    教科書 §7.3（p.134〜135）より。本文には合成モーメントを M と書いた所がありますが、T と同じものです（この教材では T に統一）。

    剛体が平面運動をするときは、(7.13) と (7.14) を別々に立てて連立して解きます。(7.13) の左辺は力の合力なので、同じ大きさ・向きの力ならどこに加えても重心の加速度は同じです。(7.14) の左辺は重心のまわりのトルクなので、作用点が重心からどれだけ離れているかで回転が決まります。

    実験　重心からずれた点を押す摩擦の無い机の上の細い棒を上から見た図。d を変えて再生
    外力 F（向きは一定）トルク T（重心まわり）0.25 s ごとの棒の位置（薄い）d = 0 の棒（重心を押した場合）
    重心の加速度 a = F/m
    最初の角加速度 α = Fd/IG
    いまの棒の角 φ
    いまのトルク T = Fd cos φ
    数値積分から求めた G の加速度

    重心 G の位置 xG（d によらない）

    棒の回った角 φ（青：いまの d、灰：d = 0）

    棒は質量 m = 1.0 kg、長さ l = 1.0 m、IG = ml²/12 = 0.0833 kg·m²。力は F = 2.0 N で、最初は棒に直角（画面の右向き）です。図は 1 m を 190 px、力の矢印は 1 N を 30 px にしています。力の向きは一定のまま、作用点は棒とともに動くので、棒が回ると力と棒のなす角が変わり、重心まわりのトルクは T = Fd cos φ（φ は棒が最初の向きから時計回りに回った角）で変わります。運動は運動方程式 F = ma と Fd cos φ = IG φ̈ を数値積分（4 次のルンゲ・クッタ法、刻み 0.5 ms）で解いて描いています。φ が 90° になるとトルクが 0 になり、それを越えると逆向きになるため、棒は 90° を中心に行き来します。

    確かめること　(1) どの d でも G の位置の曲線は同じ（a = F/m = 2.00 m/s² の等加速度で、G は直線上を進む）。(2) d = 0 では T = 0 なので棒は回らず、薄く重ねた d = 0 の棒と一致する。(3) d を大きくするほど最初の α が大きい。
    作用点を d = 0.25 m にすると、重心の加速度 a と最初の角加速度 α はいくらか（F = 2.0 N、m = 1.0 kg、l = 1.0 m）。

    式(7.13)から a = F/m = 2.00 m/s²（d = 0.50 m のときと変わらない）。式(7.14)から α = Fd/IG = 2.0 × 0.25/0.0833 = 6.00 rad/s²（d = 0.50 m の 12.0 rad/s² の半分）。図で d = 0.25 m にして確かめましょう。

    斜面を転がる球

    教科書 §7.3　例題7.8　図7.11　p.135〜136
    例題7.8水平となす角 θ の斜面の上を、半径 R、質量 m の球が滑らずに転がるときの、重心の加速度 a を求めよ。

    球には重力 mg、斜面からの抗力、摩擦力 f がはたらきます。この例題の R は球の半径で、第1・2回で抗力に使った R とは別です。そこでこの節では抗力に記号を付けず、「抗力」と書きます。抗力は斜面に垂直で、大きさは mg cos θ です。摩擦力 f は斜面上向きに仮定します（解いた結果は正になります）。

    斜面に沿う方向の合力は F = mg sin θ − f です。重心の並進運動には式(7.13)、重心を通る軸のまわりの回転には式(7.14)を使います。

    mg sin θ − f = ma(a)
    fR = IGα(b)

    摩擦力 f が重心のまわりにつくるトルクは T = fR です（重力と抗力の作用線は重心を通るので、トルクをつくりません）。球の慣性モーメントは例題7.6 の結果です。

    IG = 2mR25(c)

    滑らずに転がるときは、接点の速さが 0 なので、重心の加速度と角加速度が結びつきます。

    a = Rα(d)

    式(c)(d)を式(b)に代入すると、f が a で表せます。

    f = 2ma5(e)

    式(e)を式(a)に代入して a について解くと、mg sin θ = ma + 2ma/5 = (7/5)ma です。

    a = 57 g sin θ

    滑る物体（摩擦が無い場合）の g sin θ より小さいのは、摩擦力 f が重心の加速度を減らし、同時に重心まわりのトルクで球を回しているからです。式(e)から f = (2/7)mg sin θ は正で、仮定した向き（斜面上向き）が正しいことも分かります。

    a = g sin θ1 + IG/(mR2)

    糸を巻いた円柱

    教科書 §7.3　例題7.10　図7.13　p.136〜137
    例題7.10軽い糸を巻きつけた、質量 m、半径 R の円柱がある。床との摩擦は十分あるものとして、糸の一端に力 F を加えたとき（糸は円柱の上端から水平に引く）、円柱の中心 O の加速度 a を求めよ。

    円柱と床の間の摩擦力を f とします。教科書は f を後ろ向き（F と逆向き）と仮定して立式しています。前向きを正とすると、重心の並進運動方程式は次のとおりです。

    F − f = ma(a)

    円柱にはたらくトルクは、上端で引く F による FR と、接点の摩擦力（後ろ向きの仮定）による fR の和 T = FR + fR です（どちらも同じ向きの回転）。重心を通る軸に関する円柱の慣性モーメントは mR²/2（例題7.5）です。

    (F + f)R = mR22α(b)

    滑らずに転がる条件 a = Rα を式(b)に入れると F + f = ma/2 です。式(a)と足して f を消すと、

    a = 4F3m

    が得られます。ここで式(a)に戻すと f = F − ma = F − 4F/3 = −F/3 と負になります。仮定した向き（後ろ向き）と逆なので、実際の摩擦力は前向きで、大きさ F/3 です。摩擦が無いとすると、F だけで a = F/m、Rα = 2F/m となり、接点は床に対して後ろ向きに F/m で滑ろうとします。これを止めるように、床が前向きの摩擦力を出すのです。

    加速度 a = 4F/(3m)
    角加速度 α = a/R
    式(a)から f = F − ma
    時刻 t

    上端（糸を引く点）の速さ 2v

    矢印の長さは F を 150 px とした力の大きさに比例し、f = F/3 の矢印は 50 px です（F を変えても長さは同じで、値は数字で示します）。鉛直方向の重力と床からの抗力はつり合うので描いていません。再生では a が一定なので等加速度で動き、1 m を 60 px で描きます（動く距離が 4 m に達するか 3 s たつと止まります）。滑らないので、上端の速さは中心の速さ v に回転による Rω = v を加えた 2v です。

    引く力を F = 6.0 N にする（m = 2.0 kg、R = 0.20 m）。a と f はいくらか。

    a = 4F/(3m) = 4 × 6.0/(3 × 2.0) = 4.00 m/s²、f = F − ma = 6.0 − 2.0 × 4.00 = −2.00 N（= −F/3）。負なので、実際の摩擦力は前向きで 2.00 N です。図の F を 6.0 N にして確かめましょう。

    まとめと次回

    • 剛体の平面運動：ΣF = ma（式7.13、重心の並進運動）と ΣT = IGα（式7.14、重心を通る軸のまわりの回転）を連立して解く。本文の合成モーメント M は T と同じもの。重心の加速度は力の作用点によらず、回転は重心まわりのトルクで決まる。
    • 滑らずに転がる条件：a = Rα。
    • 例題7.8（斜面を転がる球）：a = (5/7)g sin θ、f = (2/7)mg sin θ（斜面上向き）。一般に a = g sin θ / (1 + IG/(mR²))。
    • 例題7.9（切り離された直後の棒）：a = 3g/4、F = mg/4（切断前は mg/2）。
    • 例題7.10（糸を巻いた円柱）：a = 4F/(3m)。摩擦力は仮定の向きで立式し、解いた符号で実際の向きを知る（f = −F/3 → 前向き）。
