    本時の目標と進め方

    教科書 §6.2〜6.3　p.110〜119

    第1回では、運動方程式 F = ma（式6.1）を使って、力から加速度を求めました。今回はこの式を移項して書き直すところから始めます。

    F = ma　→　F + (−ma) = 0

    右の形では、運動方程式が力のつり合いの式と同じ見た目になります。−ma を慣性力と呼ぶことで、動いている物体の問題も、基礎力学Ⅰで学んだ静力学と同じ手順で解けます。この見方を、次の順に使っていきます。

    慣性力とダランベールの原理

    教科書 §6.2　p.110
    慣性力とダランベールの原理
    運動方程式(6.1)を次のように書き直す。
    F + (−ma) = 0(6.2)
    −ma を慣性力（inertia force）という。式(6.2)は、外力 F と慣性力 −ma の動釣合いの式と解釈でき、動力学の問題を静力学と同様に扱える。これをダランベールの原理（d'Alembert's principle）という。
    教科書 §6.2（p.110、図6.8）より
    • 慣性力の大きさは ma、向きは加速度と逆向きです（符号 − が逆向きを表します）。
    • 慣性力は、ひもや床のように「相手の物体」が及ぼす力ではなく、第三法則の反作用でもありません。加速度運動する物体と一緒に動く人から見ると、物体に −ma が働いているように見える、という力です。
    • 外から見る場合は F = ma（運動方程式）、一緒に加速する人から見る場合は F + (−ma) = 0（動釣合い）。どちらで書いても同じ式です。
    図解　外力・加速度・慣性力（図6.8 相当）なめらかな水平面。F と m を変え、見る立場を切り替える
    外力 F加速度 a慣性力 −ma（破線）
    加速度 a = F/m
    慣性力 −ma
    F + (−ma)

    F・ma の矢印は同じ縮尺（1 N あたり 6 px）です。加速度 a の矢印は別の量なので別の縮尺（1 m/s² あたり 8 px）です。慣性力は破線で描いています。「一緒に加速する人から見る」を選ぶと、地面（目盛り）が後ろへ流れ、物体は静止して見えます。このとき物体は、右向きの F と左向きの慣性力がつり合っているように見えます。

    質量 4.0 kg の物体に、水平右向きに 10 N の力が働いて加速している。慣性力の大きさと向きはどうなるか。

    加速度は a = F/m = 10/4.0 = 2.5 m/s²（右向き）。慣性力は大きさ ma = 4.0 × 2.5 = 10 N、向きは加速度と逆の左向きです。右向きの F = 10 N とつり合い、F + (−ma) = 10 + (−10) = 0 になります。

    例題6.5 ― エレベータの床から受ける力

    教科書 例題6.5　p.110〜111
    教科書 例題6.5下の図に示すようにエレベータが加速度 a = 1 m/s² で上昇するとき、質量 m = 75 kg の人が床面から受ける反力はどれほどか。また、エレベータが等速度で昇降しているときはどうなるか。

    人に注目し、上向きを正とします。人に働く力は、足元から受ける床の抗力 R（上向き）と重力 mg（下向き）です。人は上向きに加速度 a で動くので、慣性力 ma は下向きに働きます（図6.10）。

    1. 動釣合いの式（上向き正）：
      R − mg − ma = 0(a)
    2. (a)を R について解く：
      R = m(g + a) = 75 × (9.80 + 1) = 810 N(b)
    3. 等速のとき a = 0 なので
      R = mg = 75 × 9.80 = 735 N

    教科書は g = 9.8 で計算していますが、9.80 でも 810 N、735 N と同じ値になります。上昇しながら加速すると、床から受ける力は重さ 735 N より ma = 75 N だけ大きくなります。体重計に乗っていれば、R/g = 82.7 kg を示します。

    実験　エレベータの中の人の自由体線図（図6.10）加速度 a（上向きを正）と質量 m を変える

    エレベータ（外から見た図）

    人の自由体線図（周囲は描かない）

    床の抗力 R（足元から）重力 mg慣性力 ma（破線）加速度 a
    床から受ける力 R = m(g + a)
    重さ mg
    慣性力 ma（向き）
    体重計の読み R/g

    自由体線図の R・mg・ma の矢印は同じ縮尺です（縮尺は力の最大値に合わせて自動で決め、上に表示します。既定値では 100 N あたり約 35 px で、力が大きいほど小さくなります）。R と mg は同じ作用線上にあるため、左右にずらして描いています（R は左の足元から、mg は重心から、慣性力は右にずらして重心から。慣性力は a が小さいと短くなります）。加速度 a の矢印は別の量なので別の縮尺です。慣性力は破線です。

    ケーブルが切れて、エレベータが自由落下（a = −g）したとき、人が床から受ける力 R はいくらか。

    R = m(g + a) に a = −g を代入すると R = 0。上向きの慣性力 mg が重力とちょうど打ち消し合い、床を押さなくなります（体重計は 0 を示します）。上の図の a の範囲（−5〜+5 m/s²）では 0 にならず、a = −5 でも R は重さの約半分です。

    流体の抵抗と終速度

    教科書 式(6.3)〜(6.6)　p.111〜112

    空気や水などの流体の中を動く物体は、動く向きと逆向きの抵抗力を受けます。教科書は、これを次のように表します。

    R = κvn(6.3)

    κ（カッパ）は流体の密度や物体の形状に関係する比例定数、n は速度が小さいとき 1、大きいとき 2 です。この節の R は「抵抗力」で、前節の床の抗力 R とは別のものです。以下では n = 2 とします。

    図6.11 のように、物体を静かに（v0 = 0）落とします。下向きを正、t = 0 での位置を y = y0 とします。物体に働く力は、重力 mg（下向き）と抵抗力 κv2（上向き）です。

    1. 合力は
      F = mg − κvn(6.4)
    2. n = 2 として、慣性力 −ma を加えた動釣合いの式にすると
      mg − κv2 + (−ma) = 0(6.5)
    3. 落下が続くと速度が増し、抵抗力が大きくなります。やがて ma = 0（加速度 0）になる速度を終速度（final velocity）Vf といいます。(6.5)で ma = 0、v = Vf とおくと
      Vf = mgκ(6.6)

    終速度では、抵抗力と重力がつり合っています。それ以後は一定の速さで落ち続けます。

    実験　落下する球と抵抗力（図6.11）m・κ を変えて「落とす」。スライダーで速さを直接動かしてもよい
    終速度 Vf = √(mg/κ)
    速さ v
    抵抗力 κv²
    加速度 a
    経過時間 t
    落下距離 y
    重力 mg抵抗力 κv²加速度 a

    重力と抵抗力は同じ作用線上にあるため、左右にずらして描いています（実際は球の中心を通る同じ鉛直線上）。重力と抵抗力の矢印は同じ縮尺で、重力 mg の矢印をいつも 110 px にそろえています（抵抗力は v ≦ Vf の範囲で mg を超えないので、はみ出しません）。加速度の矢印は別の縮尺（g = 60 px）です。左の目盛りは、球が下へ進むほど上へ流れます（球は図の中で動かさず、地面側を動かして描いています）。「落とす」の再生は、経過時間 t が最長でも約 6 秒に収まるよう、Vf が大きいときは実際の時間より速く再生します（読み出しの t は実際の経過時間）。速さのスライダーの上限を 0.99 にしているのは、v は Vf に近づくだけで達しないためです（教科書 p.113）。

    同じ球で、κ を 2 倍にすると終速度は何倍になるか。質量 m を 2 倍にすると何倍か。上の図で確かめよう。

    Vf = √(mg/κ) より、κ を 2 倍にすると 1/√2 ≒ 0.707 倍、m を 2 倍にすると √2 ≒ 1.41 倍になります。形が空気の抵抗を受けにくいほど κ が小さく、終速度が大きくなります。

    速度の時間変化 ― 式(6.7)〜(6.9)

    教科書 式(6.7)〜(6.9)　p.112

    式(6.5)の a を dv/dt に直し、変数分離して積分すると、速度 v を時間 t の関数として表せます。結果は次のとおりです。

    v = e2gt/Vf − 1e2gt/Vf + 1Vf(6.9)

    これは v = Vf tanh(gt/Vf) と同じです。t → ∞ で v → Vf ですが、いくら時間が経っても Vf に達することはなく、近づくだけです。

    導出を見る（式(6.7)〜(6.9)）

    (6.5)の a を dv/dt として整理し、(6.6)の κ = mg/Vf² を使うと、変数 v と t を分けられます。

    dvVf2 − v2 = gVf2dt(6.7)

    両辺を積分します（左辺は部分分数に分けて積分）。

    12Vf log Vf + vVf − v = gVf2t + C(6.8)

    t = 0 で v = 0 なので、左辺の log の中が 1、log 1 = 0 より C = 0。両辺に 2Vf を掛けて指数をとり、v について解くと式(6.9)になります。

    グラフ　速度の時間変化 v(t)終速度 Vf を変え、再生する
    速度 v（式6.9）
    v/Vf
    抵抗なしなら gt
    v が 0.99Vf になる時刻

    実線が式(6.9)、水平の破線が Vf、灰色の線が抵抗がないときの自由落下 v = gt です。最初は両者が重なっていて、速度が増すにつれて抵抗力が効き、曲線が Vf に近づきます。横軸・縦軸の範囲は Vf に合わせて自動で変わります。

    t = Vf/g のとき、速度は Vf の何割か。

    式(6.9)で 2gt/Vf = 2 なので、v = (e² − 1)/(e² + 1) Vf = (7.389 − 1)/(7.389 + 1) Vf = 0.762 Vf。上のグラフで、点が t = Vf/g の位置（図に○で表示）にあるとき確かめられます。

    例題6.6 ― 落下距離と速度

    教科書 例題6.6　p.112〜113
    教科書 例題6.6前節の図において、空中での物体の任意位置 y での速度を求めよ。

    時間ではなく位置の関数として表したいので、加速度を a = v dv/dy（dv/dt = (dv/dy)(dy/dt) より）とおき、(6.5)から変数分離します。

    1. v dvVf2 − v2 = gVf2dy(a)
    2. 積分すると
      −log(Vf2 − v2) = 2gVf2y + C(b)
    3. y = 0 で v = 0 より C = −log Vf²。これを戻して v について解くと
      v = 1 − e−2gy/Vf2 Vf(d)

    y → ∞ で v → Vf です。抵抗がなければ v = √(2gy)（式5.17）で速度はいくらでも増えますが、抵抗があると Vf で頭打ちになります。

    実線が式(d)、灰色の線が抵抗なしの v = √(2gy)、水平の破線が Vf です。y が小さいうちは両者がほとんど重なり、y が Vf²/(2g) 程度になるあたりから差が開きます。横軸の範囲（スライダーの上限も）は Vf に合わせて自動で変わり、灰色の線は縦軸の上端で打ち切っています。

    例題6.7 ― 加速する容器の水面

    教科書 例題6.7　p.113〜114
    教科書 例題6.7容器に水を入れ水平方向に 3 m/s² の加速度で運動させたとき、水面の傾きを求めよ。

    水面の微小な部分（質量 dm）に注目します。水と一緒に加速する人から見ると、dm には重力 dm·g（下向き）と慣性力 dm·a（加速度と逆向き）が働きます。水面は静止して見えるので、動釣合いが成り立ち、合力は水面に垂直になります。

    1. 合力は鉛直下向きから角 θ だけ傾き、水面はこれに垂直なので、水面は水平面に対して θ 傾きます。
    2. tan θ = dm · adm · g = ag = 39.8 = 0.3061,　θ = 17.02°

    dm は約分されて消えます。つまり水面の傾きは、水の量にも容器の大きさにも関係しません。

    重力 dm·g慣性力 dm·a（破線）合力（水面に垂直）加速度 a
    tan θ = a/g
    水面の傾き θ
    水位（後ろ側／前側）はもとの深さの

    右の図の矢印は dm を共通にして描くので、長さは g と a に比例します（同縮尺、1 m/s² あたり 12 px）。左の図の水面の傾きと、右の図の合力の傾き θ は等しくなります（水面は合力に垂直）。水は容器の幅の半分の深さから始めており、a = g（θ = 45°）で水面がちょうど右下の角に届きます。これより大きい a では水面の形が変わるため、スライダーの上限を g にしています。

    水の量を 2 倍にしたら、水面の傾きは変わるか。

    変わりません。式 tan θ = a/g には、dm も容器の大きさも出てきません。傾きは加速度 a だけで決まります（水が多ければ、傾いたときに容器からあふれやすくなる点だけが違います）。

    求心力 ― 円運動を続けさせる力

    教科書 §6.3 式(6.10)　p.114〜115

    半径 r の円周上を、速さ v で等速円運動する質量 m の物体を考えます（図6.13）。速さは一定でも、速度の向きが変わり続けるので、物体には中心 O に向かう加速度（法線加速度）があります。

    an = v2r = rω2　（v = rω）

    運動方程式 F = ma より、物体には中心に向かう次の大きさの力が働いていなければなりません。

    求心力
    F = mv2r = m r ω2(6.10)
    円運動する物体に働く、中心に向かうこの力を求心力（centripetal force）という。ひもの張力や万有引力が求心力を与える例である。
    教科書 §6.3（p.114、図6.13）より

    求心力は、新しい種類の力ではなく、ひもの張力・万有引力・摩擦力などが中心向きに働いた結果につけた名前です。下の図で、ひもを切ってみましょう。

    実験　等速円運動と求心力（図6.13）m・r・v を変える。「ひもを切る」で接線方向へ飛び出す
    求心力 F（ひもの張力）速度 v
    求心力 F = mv²/r
    角速度 ω = v/r
    一周の時間 2πr/v

    求心力 F の矢印の長さは力に比例します（縮尺は上の表示のとおり。F が大きいときは縮尺を自動で縮めます）。速度 v の矢印は別の量なので別の縮尺（1 m/s あたり 8 px）です。ひもを切ると求心力がなくなり、物体はその瞬間の速度のまま、円の接線方向へ直進します（第一法則）。

    速さ v を 2 倍にすると、求心力 F は何倍か。半径 r を 2 倍にすると（v は一定）何倍か。

    F = mv²/r は v の 2 乗に比例するので、v を 2 倍にすると 4 倍。r に反比例するので、r を 2 倍にすると 1/2 倍です。同じ速さでも、急なカーブ（r が小さい）ほど大きな求心力が必要になります。

    遠心力 ― 一緒に回る人から見た慣性力

    教科書 §6.3　p.114〜115
    遠心力
    求心力によって円運動する物体には、その反作用として求心力に等しい大きさの外向きの慣性力が働く。これを遠心力（centrifugal force）という。
    教科書 §6.3（p.114〜115）より
    教科書の記述の訂正　教科書は遠心力を「求心力の反作用」と書いていますが、これは誤りです。第三法則の反作用は別の物体に働く力です。おもりがひもを外へ引く力（ひもに働く力）は求心力の反作用ですが、教科書の遠心力は、一緒に回る立場でおもり自身に働くとみなす慣性力で、別のものです。

    前の節の円運動を、見る立場を変えて考えます。

    • 外から見る：物体は求心力 F（ひもの張力）だけを受け、円運動している。運動方程式 F = m an（中心向きを正）。
    • 物体と一緒に回る人から見る：物体は静止している。そこで、求心力 F と外向きの慣性力（遠心力）がつり合うと考えられる。F + (−m an) = 0。遠心力の大きさは m v²/r = m r ω²。

    どちらで考えても、式の内容は同じです。慣性力は、前節（§6.2）の −ma のうち、加速度 a が中心向きの法線加速度のときのものです。

    図解　同じ円運動を2つの立場で見る見る立場を切り替える
    求心力 F（ひもの張力）遠心力（慣性力、破線）
    求心力 F = mv²/r
    遠心力の大きさ mv²/r
    合計（動釣合い）

    求心力と遠心力の矢印は同じ縮尺です（縮尺は上の表示のとおり。大きいときは自動で縮めます）。「一緒に回る人から見る」では、背景の目印（周りの短い線）が物体と逆向きに回って見え、物体は静止しています。遠心力は破線で描いています。

    ひもを切ったら、物体は外向きに飛び出すか。

    外から見ると、ひもを切った瞬間の速度の向き（円の接線方向）へ直進します。中心から遠ざかっては行きますが、「遠心力で外向きに飛び出す」のではありません。外向きの慣性力（遠心力）は、一緒に回る人から見て、ひもの張力とつり合っていたものです。ひもが切れて張力がなくなれば、つり合いが崩れ、一緒に回る人からは物体が外へ離れていくように見えます。

    例題6.8 ― 鉛直面内で回すバケツの水

    教科書 例題6.8　p.115〜116
    教科書 例題6.8水を入れたバケツに長さ l の針金をつけて、鉛直面を回転させる。回転数を n [rpm] とするとき、バケツが頂点を通過するときに水がバケツから受ける力 P を求めよ。ここでバケツの深さに比較して針金の長さは十分大きいものとする。

    頂点では、バケツの底が上、口が下を向きます。水（質量 m）には、重力 mg（下向き）、バケツの底から受ける力 P（下向き、水を底に押し付ける向き）が働きます。水と一緒に回る人から見ると、さらに遠心力 F（上向き）が働きます。頂点でこれらはつり合います。

    1. 動釣合い（上向き正）：
      F − mg − P = 0
    2. 遠心力は F = mv²/l。回転数 n [rpm]（1 分間の回転数）から、ω = 2πn/60、v = lω = l × 2πn/60。
    3. P = F − mg = m(4π2n2l3600 − g)

    P は水がバケツの底から押される力なので、負にはなれません。P < 0 になる回転数では、水を底へ押し付けられず、水はこぼれます。境目は P = 0（F = mg）で、n0 = (60/2π)√(g/l) です。

    実験　頂点での水とバケツ（図6.14）回転数 n と針金の長さ l を変える

    バケツの回転（鉛直面）

    頂点での水の自由体線図

    重力 mg底から受ける力 P遠心力 F（破線）
    速さ v = l 2πn/60
    遠心力 F = mv²/l
    重力 mg
    底から受ける力 P = F − mg
    P = 0 になる回転数 n0

    右の自由体線図の F・mg・P の矢印は同じ縮尺です（縮尺は上の表示のとおり。大きいときは自動で縮めます）。同じ鉛直線上にある 3 つの力は、重ならないよう左右にずらして描いています。遠心力は破線です。P < 0 のときは P の矢印を描かず、左の図で水が口からこぼれるようすを描きます。

    針金の長さ l = 1.5 m（既定値）で、水がこぼれない最小の回転数 n0 は約何 rpm か。上の図の表示と合わせよ。

    P = 0 とおくと v² = gl。n0 = (60/2π)√(g/l) = 9.549 × √(9.80/1.5) = 9.549 × 2.556 ≒ 24.4 rpm。それより遅いと、頂点で遠心力が重力に足りず、水はこぼれます。m が式に残らないことにも注目してください（水の量には関係しない）。

    例題6.11 ― 人工衛星の速度と周期

    教科書 例題6.11　p.118〜119
    教科書 例題6.11高さを考慮した場合の重力加速度とその高さにおける人工衛星の速度 v と公転周期 T はどうなるか。

    地球の中心から距離 y の位置での重力加速度は、万有引力が距離の 2 乗に反比例するので d²y/dt² = −k/y² と書けます。地表（y = R）で −g に等しいことから k = gR² です。ここの R は地球の半径で、抗力ではありません。地表からの高度を y′ = y − R とすると、高度 y′ での重力加速度は

    g′ = gR2(y′ + R)2(f)

    人工衛星は、この重力（万有引力）を求心力として円運動します。半径 y′ + R の円運動で、遠心力と万有引力がつり合うとして、

    1. mv2y′ + R = mgR2(y′ + R)2(g)
    2. v = gR2y′ + R(h)
    3. 周期は、円周 2π(y′ + R) を速さ v で割って
      T = 2πR(y′ + R)3g(i)

    R = 6370 km、y′ = 800 km（g = 9.80 m/s² = 9.80×10⁻³ km/s²）のとき、v = 7.447 km/s、T = 6049 s（1時間40分49秒）です。

    実験　高度と衛星の速度・周期高度 y′ を変える
    万有引力 mg′（求心力）速度 v
    重力加速度 g′ = gR²/(y′ + R)²
    速さ v（式h）
    周期 T（式i）
    軌道半径 y′ + R

    地球と軌道の半径の比は実際のとおり（地球の半径 R = 6370 km）です。軌道が常に同じ大きさで描かれるよう、縮尺は高度に応じて自動で変わります。矢印の長さは重力加速度 g′ に比例し（1 m/s² あたり 12 px、常に同じ縮尺）、速度の矢印は別の量なので別の縮尺です。アニメーションは 1 周を約 5 秒に縮めており、実際の周期は上の値です。高度が上がるほど、v は小さく、T は長くなります。

    まとめと次回

    • 慣性力とダランベールの原理：F + (−ma) = 0（式6.2）。慣性力 −ma は加速度と逆向き。外力と慣性力の動釣合いとして、動力学の問題を静力学と同様に扱える。
    • エレベータ（例題6.5）：R = m(g + a)（上向き正）。m = 75 kg、a = 1 m/s² で 810 N、等速で 735 N。
    • 流体の抵抗：R = κvn（式6.3）。n = 2 のとき終速度 Vf = √(mg/κ)（式6.6）。速度は Vf に近づくだけで達しない（式6.9）。例題6.6：v = √(1 − e−2gy/Vf2) Vf。
    • 加速する容器の水面（例題6.7）：tan θ = a/g。a = 3 m/s² で θ = 17.02°。
    • 求心力：F = mv²/r = mrω²（式6.10）。遠心力は、これと同じ大きさで外向きの慣性力。
    • 円運動の例題：バケツ P = m(4π²n²l/3600 − g)（P < 0 でこぼれる）、円錐振り子 v = √(rg tan θ)・T = mg/cos θ（2.38 m/s、22.6 N）、カーブ tan θ = v²/(rg)（10.05°）、人工衛星 v = √(gR²/(y′ + R))（7.447 km/s）・T = 6049 s。
