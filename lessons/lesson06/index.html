    角運動量 ― 式(8.6)・図8.4

    教科書 §8.3　図8.4　p.146〜147

    図8.4 のように、慣性モーメント I の回転体（円板）に、一定のトルク T = Fr が時間 t だけ働き、角速度が ω0 から ω に変化したとします。平均角加速度 α は次のとおりです。

    α = ω − ω0t

    これを第3回で学んだ角運動方程式 T = Iα（式(7.5)）に代入すると、次の式が得られます。

    T = Iα = Iω − Iω0t(8.6)
    角運動量

    慣性モーメント I と角速度 ω の積 Iω を角運動量といいます。大きさ・方向・向きを持つベクトル量で、単位は [kg·m²/s] です。方向は回転軸の方向です。この教材では、同じ軸のまわりの回転を、向きを符号で表して扱います（反時計回りを正）。

    式(8.6)は、物体の単位時間当りの角運動量の変化が、その物体に働くトルクに等しいことを表します。また、トルクが働かなければ角運動量は変化しません。

    実験　トルク T = Fr を時間 t だけ加えたときの角運動量の変化スライダーを動かす／「再生」で回す
    トルク T = Fr
    角加速度 α = T/I
    角速度 ω = ω0 + αt
    角運動量 Iω0
    力積のモーメント Tt
    角運動量 Iω = Iω0 + Tt

    図の見方：円板の縁の赤いまっすぐな矢印が接線力 F（円板が回っても向きは変わらない設定で、縁の右端に加えます。縮尺は 1 N = 10 px で固定）、赤い曲がった矢印がトルク T、灰青の細い曲がった矢印が角速度 ω で、向きだけを表します（長さは量を表しません）。円板の大きさは半径 r に合わせて変わります。下の棒グラフは、Iω0 の棒の先に Tt（赤の破線）の棒を継ぎ足すと Iω の棒の長さになることを表します。

    既定（I = 0.50 kg·m²、ω0 = 2.0 rad/s、r = 0.20 m、t = 3.0 s）から F を −5.0 N にすると、ω と Iω はいくらか。

    T = Fr = −1.00 N·m、α = T/I = −2.00 rad/s²、ω = 2.0 + (−2.00)(3.0) = −4.00 rad/s、Iω = 0.50 × (−4.00) = −2.00 kg·m²/s。角運動量は Iω0 = 1.00 から、力積のモーメント Tt = −3.00 N·m·s を加えて、0 を通って負（時計回り）になります。

    質点の角運動量 ― I = mr²

    教科書 §8.3　p.147

    教科書は、質点とみなせる質量 m の物体が、ある軸から距離 r で軸のまわりを角速度 ω で回転しているとき、軸のまわりの慣性モーメントは I = mr² なので、角運動量は次のとおりだと述べています。

    Iω = mr²ω

    角運動量は r の2 乗に比例します。r を 2 倍にすると、角運動量は 4 倍になります。

    補足（教科書にはない見方）　質点の速さは v = rω、運動量の大きさは mv です。r × mv = mr²ω は Iω と同じ値になります。つまり、角運動量は「運動量に腕の長さ r を掛けたもの」と見ることもできます。
    実験　軸のまわりを回る質点の角運動量スライダーを動かす／「回す」で回転
    慣性モーメント I = mr²
    角運動量 Iω
    速さ v = rω（補足）
    運動量の大きさ mv（補足）
    r × mv（補足）

    図の見方：おもり（質点）は軽い棒で軸につながっています。棒の長さは r に比例し、1 m = 150 px です。おもりの円の大きさは質量 m に合わせて変わります。右上の灰青の曲がった矢印は角速度 ω の向き（反時計回りが正）です。右の棒グラフは、赤紫の塗りが今の角運動量 Iω、灰色の輪郭が既定値（m = 0.50 kg、r = 0.40 m、ω = 3.0 rad/s）の Iω = 0.240 kg·m²/s です。2 本は同じ縮尺で、縮尺は上に表示します。回転の表示は実際の角速度どおりです。

    既定から r を 2 倍（0.80 m）にすると、I と Iω はいくらか。

    I = mr² = 0.50 × 0.80² = 0.320 kg·m²、Iω = 0.320 × 3.0 = 0.960 kg·m²/s。既定の 0.240 の 4 倍です。角運動量は r の 2 乗に比例するので、r を 2 倍にすると 4 倍になります（ω を 2 倍にしても 2 倍にしかなりません）。

    力積のモーメントと作用時間 ― 式(8.7)(8.8)・例題8.6

    教科書 式(8.7)(8.8)　例題8.6　p.147〜148

    式(8.6)の両辺に t を掛けて整理します。

    Tt = Iω − Iω0(8.7)

    左辺は Tt = Frt = (Ft)r と書き換えられます。これは物体に作用する力積 Ft と腕の長さ r との積で、力積のモーメントといいます。

    (Ft)r = Iω − Iω0(8.8)
    力積のモーメント

    単位は [N·m·s] です。式(8.8)は「角運動量の変化量は力積のモーメントに等しい」ことを表します。N = kg·m/s² なので、N·m·s = kg·m²/s で、角運動量の単位と一致します。

    角運動量の変化量が決まっているとき、力積のモーメントも一定です。したがって、トルクの大きさと作用時間は反比例します。作用時間がきわめて短ければトルクは非常に大きく、長ければ小さくなります。走行中の車を短時間で止めようとするほど、大きなブレーキトルクが必要になります。

    例題8.6　回転数 n = 1200 rpm で回転している直径 D = 300 mm、質量 m = 30 kg の円板状のはずみ車を t = 5 s で停止させたい。停止に要するトルク T と接線力 F を求めよ。
    直径 D = 300 mm なので半径は r = 0.15 m。円板の慣性モーメントは I0 = ½mr² = 0.3375 kg·m²。ω0 = 2π × 1200/60 = 125.7 rad/s。式(8.6)より T = I0(0 − ω0)/t = −8.48 N·m、F = |T|/r = 56.5 N。教科書は途中の値を 0.338・126 に丸めてから掛けるので −8.52 N·m、56.8 N となっています。T の負号は「回転と逆向き」の意味です。
    実験　はずみ車を止めるまでの時間 t を変える角運動量の変化量は一定、トルクは t に反比例
    慣性モーメント I0 = ½mr²
    角速度 ω0 = 2πn/60
    角運動量の変化量 −Iω0
    トルク T = −Iω0/t
    接線力 F = |T|/r
    力積のモーメント Tt

    図の見方：はずみ車の直径は 300 mm（質量 30 kg）で固定です。縁の右端に加わる赤いまっすぐな矢印が、ブレーキの接線力 F（回転と逆向き）です。矢印の縮尺は F の大きさに合わせて段階的に変わり、上の文に表示します。赤い曲がった矢印がトルク T、灰青の細い曲がった矢印が角速度 ω で、向きだけを表します。下の T–t グラフは、横軸 0〜10 s、縦軸 0〜−100 N·m に固定し、T は負なので下向きに描きます。濃い赤の部分は再生中に進んだぶんです。灰色の輪郭は例題8.6（t = 5 s）の長方形で、比較の基準です。長方形の面積（力積のモーメント）は t によらず角運動量の変化量 −Iω0 に等しく、t が短いと幅が狭くて背が高く、長いと幅が広くて背が低くなります。枠に入らない部分は枠で切って描き、実際の値を文字で添えます。

    例題8.6 で、止める時間を 2 倍の 10 s にすると、トルクと接線力はいくらになるか。

    角運動量の変化量（力積のモーメント）は同じ −42.4 N·m·s なので、トルクは時間に反比例し半分になります。T = −42.4/10 = −4.24 N·m、F = 4.24/0.15 = 28.3 N。短い時間で止めようとするほど、大きなブレーキトルクが必要です。

    時間的に変化するトルク ― 式(8.9)

    教科書 式(8.9)　p.148

    トルク T が時刻 t1 から t2 まで時間的に変化する場合は、次のとおりです。

    ∫t₁t₂ T(t) dt = Iω − Iω0(8.9)

    左辺の積分は、T–t グラフの曲線と横軸で囲まれた面積です。つまり、面積が力積のモーメントであり、角運動量の変化量に等しくなります。トルクが一定なら面積は長方形で Tt、式(8.7)と同じです。

    §8.3 に準拠した独自の図　静止した回転体（I = 0.040 kg·m²）に、0 から増えて時刻 tp で最大値 Tmax に達し、te で 0 に戻る三角形状のトルクが働くとします。面積は ½Tmaxte です。
    実験　三角形状のトルクがつくる角速度山の位置 tp を動かしても面積は変わらない
    力積のモーメント（面積）= ½Tmaxte
    終わりの角速度 ω = 面積/I
    回転数に直すと
    同じ面積の一定トルク（幅 te）

    図の見方：グラフの横軸は 0〜1.00 s、縦軸は 0〜4.0 N·m に固定です。赤の破線の輪郭が三角形状のトルク、塗りつぶしが再生で進んだぶんの面積です。再生では、トルクが働く間（0〜te）に円板が回り始め、そのあと同じ時間だけ、トルクが 0 のまま一定の角速度で回り続けます（角運動量が変わらないことの確認です）。灰青の曲がった矢印は角速度の向きです。「同じ面積の一定トルクを重ねる」を押すと、幅 te、高さ Tmax/2 の長方形（面積が等しい）を灰色の破線で重ねます。

    既定（Tmax = 2.0 N·m、tp = 0.20 s、te = 0.50 s）から、te を 1.00 s（Tmax = 2.0 N·m のまま）にすると、面積と終わりの角速度はいくらか。

    面積は ½ × 2.0 × 1.00 = 1.00 N·m·s、ω = 1.00/0.040 = 25.0 rad/s。働く時間が 2 倍になると、三角形の底辺が 2 倍になり、面積も角速度も 2 倍になります。なお、山の位置 tp を動かしても、面積（底辺 × 高さ ÷ 2）は変わらないので、終わりの角速度も変わりません。

    角運動量保存の法則

    教科書 §8.4　式(8.10)　図8.5　例題8.7　p.148〜149

    §8.2 では運動量保存の法則を学びました。教科書は、これと同様の考え方で、二つの回転体の接触前後の角運動量について、次の法則が成り立つと述べています（図8.5：同じ軸上に並んだはずみ車 1 と 2）。

    I1ω1 + I2ω2 = I1ω1′ + I2ω2′(8.10)
    角運動量保存の法則（教科書 式(8.10)）
    I1、I2 は回転体の重心回りの慣性モーメント、ω1、ω2 は接触前の角速度、ω1′、ω2′ は接触後の角速度です。接触の前後で、二つの回転体の角運動量の和は変わらない。

    同じ軸のまわりの回転では、回転の向きを符号で表します。最初に正の向きを決め、逆向きに回る回転体は ω を負にします。

    この式はどこから出るか

    教科書は式(8.10)の導出を書いていません。§8.2（式(8.5)）と同じ形で考えてみましょう。接触している間、回転体 1 と 2 は接触面で力を及ぼし合います。この 2 つの力は作用・反作用（第1回）なので、共通の軸のまわりのトルクは大きさが等しく向きが逆です。回転体 1 が受けるトルクを −T、回転体 2 が受けるトルクを +T とし、接触の時間を Δt とします。それぞれに式(8.7)（Tt = Iω − Iω0）を使います。

    回転体 1：(−T)Δt = I1ω1′ − I1ω1
    回転体 2：(+T)Δt = I2ω2′ − I2ω2

    両辺を加えると、左辺は (−T)Δt + (+T)Δt = 0 になり、式(8.10)が得られます。変わるのは各回転体の角運動量で、保存されるのはその和です。

    教科書の導出の前提（補足）　上の導出が成り立つのは、外からのトルク（軸受の摩擦など）の力積のモーメントが無視できるとき、そして 2 つの回転体が同じ軸のまわりに回るときです。接触の時間が短ければ、軸受の摩擦のトルクが働く時間も短く、無視できます。この前提は教科書に明記されていないので、補足として書いています。
    例題8.7回転数 n1 = 1200 rpm のはずみ車 1（I1 = 0.5 kg·m²）と、回転数 n2 = 600 rpm のはずみ車 2（I2 = 1 kg·m²）が同じ向きに回転している。この二つのはずみ車を短時間で接触させ、一体で回転させる。接触後の回転数 n を求めよ。

    一体となった後の角速度を ω とすると、ω1′ = ω2′ = ω で、慣性モーメントは I1 + I2 です。式(8.10)から次のようになります。

    I1ω1 + I2ω2 = (I1 + I2)ω　より　ω = I1ω1 + I2ω2I1 + I2

    ω1 = 2π×1200/60 = 125.7 rad/s、ω2 = 2π×600/60 = 62.83 rad/s なので、I1ω1 = 62.8、I2ω2 = 62.8、和は 126 kg·m²/s です。ω = 125.7/1.5 = 83.8 rad/s（教科書は 83.73 rad/s と書いています。丸めずに計算すると 83.78 rad/s で、3 桁では 83.8 です）。回転数は n = 83.8×60/(2π) ≒ 800 rpm。

    ω = 2πn/60 の係数 2π/60 は式の両辺に同じように掛かるので、rpm のまま n = (I1n1 + I2n2)/(I1 + I2) = (0.5×1200 + 1×600)/1.5 = 800 rpm としても同じ答えになります。

    実験　2 つのはずみ車を接触させるI、n、Tc を動かす／再生で接触させる
    角速度 ω（灰青の細い曲がった矢印）トルク（赤の曲がった矢印。2 が受ける +T、1 が受ける −T）角運動量 Iω（赤紫の棒。2 本とも同じ縮尺）

    2 が受けるトルク +T（実線）と 1 が受けるトルク −T（破線）。面積が力積のモーメント

    角運動量 I1ω1（実線）、I2ω2（破線）、和（太い黒）

    2 が受けるトルク1 が受けるトルクI1ω1I2ω2和 I1ω1 + I2ω2

    この教材のモデル（教科書にはない設定）　接触面ですべっている間は、大きさ一定の摩擦トルク Tc が、2 つの回転体の回転数の差を縮める向きにたがいに働くとします（回転体 1 が −Tc、回転体 2 が +Tc の向き。回転数が大きい方は減り、小さい方は増える）。角速度がそろったら、以後は一体で回ります。このとき接触時間は tc = |ω1 − ω2|/(Tc(1/I1 + 1/I2)) で、Tc を変えると接触時間だけが変わり、接触後の回転数は変わりません（式(8.10)に Tc が入っていないため）。
    はずみ車 2 を逆向きに回して n2 = −600 rpm にすると、接触後の回転数はいくらか。実験で確かめてみよう。

    逆向きの回転は ω を負にします。n = (0.5×1200 + 1×(−600))/(0.5 + 1) = 0/1.5 = 0 rpm（止まる）。角運動量は I1ω1 = +62.8、I2ω2 = −62.8 で、和は 0 です。接触中、1 の角運動量は減り、2 の角運動量は増えて（負の値が 0 に近づいて）、最後に両方とも 0 になります。和は最初から最後まで 0 のままです。

    止まっている円板をのせる

    教科書 §8.4 に準拠した独自例題6.1
    例題6.1鉛直な軸のまわりに、回転数 n1 = 90 rpm で回る回転台（慣性モーメント I1 = 0.060 kg·m²）がある。その上に、止まっている円板（I2 = 0.030 kg·m²、ω2 = 0）を、同じ軸に合わせて静かにのせた。円板は台との摩擦で回り始め、やがて台と一体で回る。(1) 一体となった後の回転数 n′ を求めよ。(2) 接触の時間 tc = 0.50 s の間に円板が受ける平均のトルクを求めよ。軸受の摩擦は、接触の短い時間には無視する。

    (1)　円板をのせる前後で、2 つの回転体の角運動量の和は変わりません（式(8.10)）。のせた後は一体なので、ω′ を共通の角速度として、

    I1ω1 + 0 = (I1 + I2)ω′　より　ω′ = I1ω1I1 + I2

    ω1 = 2π×90/60 = 9.425 rad/s なので、ω′ = 0.060×9.425/(0.060 + 0.030) = 6.28 rad/s、n′ = 60.0 rpm。rpm のままでも n′ = 0.060×90/0.090 = 60.0 rpm です。

    (2)　円板が受けた力積のモーメントは、式(8.7)から角運動量の変化量に等しく、I2ω′ − 0 = 0.030×6.283 = +0.188 N·m·s。接触の時間が 0.50 s なら、平均のトルクは式(8.6)から T = 0.188/0.50 = +0.377 N·m です。台が受けるトルクは、作用・反作用で大きさが同じで逆向きの −0.377 N·m（台の角運動量の変化は 0.060×(6.283 − 9.425) = −0.188 N·m·s）。

    回転半径を変える

    教科書 §8.3〜8.4 に準拠した独自例題6.2

    フィギュアスケートのスピンでは、腕を広げて回り始め、腕を体に引き寄せると回転が速くなります。同じことは、回転いすに座って両手におもりを持ち、腕を縮めても起こります。これを角運動量で考えます。

    例題6.2回転いすに座った人（いすと人の慣性モーメント I0 = 0.040 kg·m²。腕は含めない近似）が、両手に質量 m = 1.0 kg のおもり（質点とみなす）を 1 個ずつ持ち、軸から r1 = 0.40 m の位置で、角速度 ω1 = 2.0 rad/s で回っている。腕を縮めて、おもりを軸から r2 = 0.20 m の位置まで引き寄せた。角速度 ω2 を求めよ。いすの軸受の摩擦は無視する。

    質点の慣性モーメントは I = mr²（p.147）なので、2 個のおもりを含めた全体の慣性モーメントは I = I0 + 2mr² です。おもりを引き寄せる力は軸に向かう向きで、軸からの腕の長さが 0 なので、軸のまわりのトルクを生みません。外からのトルクも無視できるので、トルクが働かなければ角運動量は変化しません（p.147）。

    (I0 + 2mr1²)ω1 = (I0 + 2mr2²)ω2

    はじめ：I = 0.040 + 2×1.0×0.40² = 0.360 kg·m²、角運動量 Iω = 0.360×2.0 = 0.720 kg·m²/s。縮めた後：I = 0.040 + 2×1.0×0.20² = 0.120 kg·m² なので、ω2 = 0.720/0.120 = 6.00 rad/s。慣性モーメントが 1/3 になったので、角速度は 3 倍です。

    実験　腕を縮める回転いすr、I0、m を動かす／再生中も r を動かせる
    角速度 ω（灰青の曲がった矢印）おもりを引き寄せる力 F（赤。軸に向かう向き）角運動量 Iω（赤紫の棒）

    この図の約束　はじめの状態は r1 = 0.40 m、ω1 = 2.0 rad/s で固定（破線の円が r1）。スライダーの r が縮めた後の距離で、既定は 0.20 m です。回転の表示は実際の 1/2 の速さにしています。3 本の棒は、それぞれ右端の数値を最大とする別々の縮尺で（I は、いすと人とおもりを合わせた全体の慣性モーメント）、点線の枠がはじめの値、色つきがいまの値です。I と ω の棒は r とともに逆に変わりますが、Iω の棒は変わりません。
    r を 0.10 m まで縮めると、I と ω2 はいくらか。距離は半分になったのに、角速度は 2 倍にならないのはなぜか。

    I = 0.040 + 2×1.0×0.10² = 0.0600 kg·m²、ω2 = 0.720/0.0600 = 12.0 rad/s。距離を半分にすると、おもりの分の慣性モーメント 2mr² は 1/4 になりますが、いすと人の I0 = 0.040 は変わりません。全体の I は 0.120 → 0.0600 と 1/2 にしかならないので、ω も 6.00 → 12.0 rad/s と 2 倍です。I0 をスライダーで 0 にすると、I は r² に比例して変わるのが確かめられます。
